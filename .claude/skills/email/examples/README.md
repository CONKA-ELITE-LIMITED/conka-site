# Email voice samples

Drop 2-3 real emails you have sent into this folder, one file each, named by register:

- `external-1.md`, `external-2.md` -- partners, suppliers, B2B clients, corporate contacts
- `internal-1.md`, `internal-2.md` -- team

Paste the email as sent (subject + body). Strip anything confidential. The /email skill matches tone, sign-off, and sentence length against these instead of its generic rules, so the more real they are, the better the drafts.
